# 🗺️ Peta Sebaran UMKM - Sungai Enam

Peta sebaran lokasi Usaha Mikro, Kecil, dan Menengah (UMKM) di wilayah **Kelurahan Sungai Enam, Kecamatan Bintan Timur, Kabupaten Bintan, Kepulauan Riau**.

## 📋 Deskripsi

Proyek ini bertujuan untuk memetakan dan menggambarkan posisi dari berbagai UMKM yang berada di daerah Sungai Enam. Peta ini dibuat menggunakan **QGIS** sebagai alat utama pengolahan data spasial.

## 📁 Struktur Folder

```
PetaSebaranUMKM/
├── 01_data_mentah/       # Data mentah (OSM, referensi, survei lapangan)
│   ├── osm/              # Data dari OpenStreetMap
│   ├── referensi/        # Data referensi pendukung
│   └── survei_lapangan/  # Hasil survei lapangan
├── 02_data_olahan/       # Data yang sudah diolah (GeoPackage, QGIS project)
├── 03_style/             # Style dan simbol untuk peta
├── 04_layout/            # Layout peta untuk pencetakan
├── 05_output/            # Hasil akhir peta (PDF, gambar)
└── dokumentasi/          # Dokumentasi proyek
```

## 🛠️ Tools

- **QGIS** - Pengolahan dan visualisasi data spasial
- **OpenStreetMap** - Sumber data dasar peta

## 📍 Lokasi

- **Kelurahan**: Sungai Enam
- **Kecamatan**: Bintan Timur
- **Kabupaten**: Bintan
- **Provinsi**: Kepulauan Riau

## 📄 Lisensi

Proyek ini dibuat untuk keperluan pemetaan UMKM di wilayah Sungai Enam.
